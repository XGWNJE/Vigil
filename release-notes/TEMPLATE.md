# 发行描述固定格式（写 release-notes/vX.Y.Z.md 时严格套用）

## 本版主题（一句话概括，必填）

**新增**
- 新功能，逐条列出

**优化**
- 体验 / 文案 / 性能改进，逐条列出

**修复**
- 问题修复，逐条列出

---

格式约定（本文件不随发布引用，仅作模板）：

- 结构固定为：「## 一句话主题」+「新增 / 优化 / 修复」三类小节，顺序固定。
- 某类无内容时整节删除（含小节标题），不留空节。
- 只写用户可感知的变化；内部重构、文档、构建杂项不写入。
- 条目以「什么变了 + 对用户意味着什么」表述，一句话一条，不堆技术细节。
