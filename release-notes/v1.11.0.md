# v1.11.0

## 自定义铃声来源：导入音频或录音，打造专属报警铃声

**新增**
- 铃声库：新增「铃声库」页，支持导入本地音频文件（复制到应用内，原文件被删也不影响报警）与现场录音两种方式添加自定义铃声，条目支持重命名、删除、试听。
- 默认铃声与每个关键词的铃声都可选用铃声库文件，选择入口与系统铃声并列。
- 铃声文件缺失时自动回落系统默认闹钟铃声并记录诊断日志，报警不会因文件失效而静默。

**优化**
- 录音功能按需申请麦克风权限，拒绝时提供引导说明，不影响其他功能。
- 设置面板改为上滑跟手展开：前段贴手指滑动，越过意图阈值即磁铁式吸附全开，下拉把手对称收回，告别「滑完才弹出来」的迟滞感。
- 返回键 / 侧边返回一次只退一个层级（子页面 → 设置面板 → 主屏），不再一次误退到主屏。
- 全面打磨交互动效与布局：页面切换滑动淡入过渡；主屏状态词交叉淡入、涟漪与开关颜色平滑过渡、核心开关圆形按压反馈；应用过滤开关/勾选切换动画；报警弹窗进入动效与酸橙边框呼吸脉冲；铃声库提示改为应用内动画暗条，录音中红点脉冲；列表项增删位移动画；已删除的铃声在设置中显示「已失效，将回落系统闹钟」而非裸路径；各页面适配状态栏/手势导航条，小按钮触控热区加大。
