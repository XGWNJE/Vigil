# v1.14.0

## 新增：内置预设报警铃声 —— 6 条语音随 APK 打包，开箱即用

**新增**
- 内置预设铃声：6 条语音（工作群有消息需要查看 / 收到一条语音消息 / 收到老婆大人的指示 尽快查看 / 注意 督导来了 / 注意安全 小心摸鱼 / 监控发现目标），无需导入即可在「默认铃声」与每个关键词的独立设置中直接选择；铃声库页可逐个试听。
- 预设在关键词级铃声里同样可用：不同关键词可绑定不同预设语音，报警时按绑定发声。

**优化**
- 选择铃声（预设 / 系统铃声 / 铃声库）后，设置行立即显示新铃声名称，不再停留旧值。
- 试听结束（播完 / 切换 / 离开页面）后，按钮状态自动还原为「试听」，不再卡在「■ 停止」。

**修复**
- 修复内置语音在部分设备上无法播放的问题：语音文件结构异常（未最终化的长度字段）已修复，播放改为全版本可靠的资源流方式；任何资源异常时自动回落默认闹钟铃声，不会静音。
