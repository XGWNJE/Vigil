## 全面屏沉浸适配、权限引导优化与猫头鹰视觉打磨

**新增**
- 首次启动新增核心权限引导弹窗，将通知使用权、发送通知（必需）与系统悬浮窗、电池白名单（推荐）清晰分级，支持顺序一键授权或稍后配置，不再反复打扰。

**优化**
- 开启全面屏 Edge-to-Edge 适配，界面底色自然填充顶部状态栏，底部导航栏背景无缝延伸至系统小白条下方，浅色与深色模式均协调统一。
- 重构设置页为「报警策略 / 核心权限 / 后台防杀 / 关于与诊断」四个分组，并将「浮窗样式」与预览合并为等宽自适应卡片，点选即预览。
- 悬浮窗权限通畅时，报警触发后不再重复弹出高优先级系统通知栏横幅，仅在未开启悬浮窗时自动切换为系统通知栏兜底提醒。
- 收紧主页猫头鹰按钮的背景渐变光晕，减弱透明度并更贴合躯干轮廓。

**修复**
- 修复猫头鹰巡逻动画侧身帧翅膀与身体之间因抠图产生的透明分离缝隙。
